 🏥 Hospital Finance Data Analysis

## 📊 Project Overview

This project analyzes hospital financial performance,
patient activity, claims, insurance payers and accounts receivable.

## 🎯 Business Objective

The objective is to identify revenue trends, collection performance,
outstanding AR, claim status and department-level financial insights.

## 📌 Key KPIs

- Total Charges: 19M
- Total Payments: 10.82M
- Outstanding AR: 8.45M
- Total Patients: 1.50K
- Collection Rate: 56.15%

## 💡 Key Business Insights

- Monitor outstanding AR to improve cash flow.
- Focus on aged receivables.
- Track denied and pending claims.
- Compare insurance payer performance.
- Monitor department-level AR days.
- Improve overall collection efficiency.
